# Guía técnica del proyecto EV02 Web

Repositorio: GA7_220501096_AA2_EV02_Modulos_software_web.

Esta guía facilita la lectura, ejecución, prueba y auditoría técnica de la evidencia EV02 de módulos de software web.

## Objetivo

Documentar un módulo web Java/JSP que permite validar formularios, navegación, uso de métodos HTTP GET y POST, conexión con base de datos y pruebas funcionales.

## Rutas principales

| Ruta | Propósito |
|---|---|
| src | Código fuente del proyecto web. |
| docs | Documentación técnica y pruebas funcionales. |
| database | Script o recursos de base de datos. |
| evidencias/EV02-JSP-FUNCIONAL | Punto de entrada para evidencias funcionales de EV02. |
| pom.xml | Configuración Maven del proyecto. |
| README.md | Presentación principal del repositorio. |
| 00_GUIA_TECNICA_PROYECTO | Guía técnica pública de navegación. |

## Documentación recomendada

- docs/EVIDENCIA_HTTP_JSP.md
- docs/PRUEBAS_FUNCIONALES.md
- README.md

## Código fuente

El código fuente principal se encuentra en la carpeta `src`.

## Base de datos

Los recursos de base de datos se encuentran en la carpeta `database`.

## Ejecución

La ejecución debe realizarse según las instrucciones del README principal y la configuración Maven definida en `pom.xml`.

## Trazabilidad

La rama estable del repositorio es `Arawkano`.

## Principio de revisión

El proyecto debe poder entenderse, ejecutarse, probarse y auditarse sin explicación verbal adicional.
