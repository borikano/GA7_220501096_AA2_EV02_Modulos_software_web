# Evidencia de formularios, JSP y metodos HTTP

Este documento resume los elementos solicitados en la evidencia web.

## Formularios identificados

- views/login.jsp
- views/formularioUsuario.jsp

## Paginas JSP involucradas

- views/login.jsp
- views/dashboard.jsp
- views/usuarios.jsp
- views/formularioUsuario.jsp
- views/error.jsp

## Metodos HTTP implementados

### GET
Usado para:
- mostrar vistas
- listar usuarios
- cargar formularios
- preparar edicion

### POST
Usado para:
- autenticar usuario
- registrar datos
- actualizar usuarios

## Servlets involucrados

- LoginServlet.java
- LogoutServlet.java
- UsuarioServlet.java

## Conclusion

La evidencia muestra el uso de formularios JSP, paginas dinamicas y metodos GET y POST dentro de un modulo web conectado con MySQL mediante JDBC.
